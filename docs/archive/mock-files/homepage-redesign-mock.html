Chatbot Fix Critical Bug

Critical Floating Chat Input Hidden After First Use

The floating chat input disappears permanently after the user sends their first message, due to session storage logic overriding the data-always-visible="true" attribute.

Before: Input hidden after first use
↑

sessionStorage: floatingChatUsed = '1' → hidden forever

After: Always visible on key pages
↑

always-visible mode: skip session storage checks entirely

Fix in floating-chat-input.js (lines 102-106):
// BEFORE (broken): if (alwaysVisible) { baseVisible = true; alreadyUsed = false; applyVisibility(); } // AFTER (fixed): if (alwaysVisible) { floatingInput.classList.remove('hidden'); baseVisible = true; // Skip session storage — always visible means always visible return; // Don't enter scroll-trigger logic }
Enhancement Error handling on submit:
// Add try-catch around chat panel open try { window.chatSidePanel.open(message); } catch (e) { console.error('[FloatingChat] Error:', e); // Show toast notification to user }

GEO — Generative Engine Optimization Score: 5.5 → 8/10

Current GEO Audit: What AI Chatbots Can (and Can't) Find

When someone asks ChatGPT, Perplexity, or Claude about AI consulting in France, can they cite Bubble Invest? Here's what's missing.

Schema Type Current Target Impact
Organization JSON-LD 8/10 9/10 Add makesOffer array
Service + Offer Schema 2/10 8/10 AI can't cite pricing or service model
Article Schema (Blog) 3/10 8/10 Blog posts invisible to AI crawlers
Pricing Schema 1/10 7/10 No structured pricing data at all
FAQPage Schema 4/10 9/10 FAQ text exists but no schema
Person + Credentials 2/10 7/10 AI can't verify founder expertise

🛠 Service + Offer Schema

Priority 1. Add Service JSON-LD to /professionnels with Quick Start Pack details: €2,000, 3 sessions, 3 weeks. Without this, AI can't answer "How much does Bubble Invest cost?"

❓ FAQPage Schema

Priority 2. Wrap existing FAQ section in FAQPage schema. FAQ text already exists in the HTML — just needs JSON-LD wrapper. Enables AI to surface Q&A directly in responses.

📄 Article Schema (Blog)

Priority 3. Add Article JSON-LD to blog posts. Currently only OG tags exist (client-side). Need server-side injection for AI crawlers that don't execute JavaScript.

👤 Person + Credentials

Priority 4. Add Person schemas for founders on About page. Include hasCredential for AWS certifications, worksFor, and knowsAbout for expertise domains.

🏠 OfferCatalog on Homepage

Priority 5. Extend existing Organization schema with makesOffer array listing both B2C (free content) and B2B (Quick Start Pack) services. Makes homepage the canonical source.

🤖 AI Crawler Directives

Priority 6. Update robots.txt to explicitly allow GPTBot, ClaudeBot, PerplexityBot. Currently no AI-specific rules. Welcome crawlers, don't block them by default.

💬 Cite-able Content Blocks

Priority 7. Add clear factual statements in parseable format: "Quick Start Pack: €2,000, 3 sessions, operational agents in 3 weeks" — AI models extract and cite these verbatim.

📊 Notion ↔ Website Alignment

Context. The Notion page has richer service details (use cases, comparison table, principles) than the website. Syncing this content to /professionnels strengthens both SEO and GEO simultaneously.

💡
Why GEO matters: When a CGP asks ChatGPT "best AI consulting for wealth advisors in France", Bubble Invest should appear. Currently, AI models have no structured data to cite your services, pricing, or credentials. These schema additions make you machine-readable and AI-citable.
