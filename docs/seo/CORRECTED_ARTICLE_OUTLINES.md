#### H2: "Multi-Factor Scoring Engine : Le Cœur du Système" (600 words)

**Introduction**: Step 2-3 of the 11-step process is where Bubble's proprietary IP shines: multi-factor scoring.

**Factor #1: Momentum (180-Day Ranking)**
- **What it is**: Stocks/ETFs that performed well in the last 6 months tend to continue performing well
- **Academic basis**: Jegadeesh & Titman (1993), Nobel Prize-winning research
- **How it works**: Rank all candidates by 180-day total return
- **Why 180 days**: Balances short-term noise with medium-term trends
- **Output**: Top 20-30% momentum winners

**Factor #2: Quality (Fundamental Overlay)**
- **What it is**: Filter out "junk" momentum (leveraged, distressed, speculative stocks)
- **Metrics**: Profitability (ROE), stability (low debt), consistent earnings
- **Why it matters**: Momentum without quality = riding bubbles (2021 meme stocks crash)
- **Configurable**: Some strategy pockets use pure momentum, others add quality filter
- **Output**: High-momentum, high-quality candidates

**Factor #3: Risk-Adjusted (Sharpe-Based)**
- **What it is**: Favor stocks with high return per unit of risk (Sharpe ratio)
- **Purpose**: Avoid high-volatility momentum (crypto-style boom-bust)
- **How it works**: Rank by Sharpe ratio (return / volatility) instead of raw return
- **Use case**: Conservative strategy pockets
- **Output**: Risk-efficient momentum candidates

**Configurable Per Strategy Pocket**:
- **Aggressive pocket**: Pure momentum (maximize upside)
- **Balanced pocket**: Momentum + quality (balance growth + stability)
- **Conservative pocket**: Risk-adjusted momentum (minimize volatility)

**Backtesting Results** (2005-2025, 20 years):
- **Pure momentum**: 12.3% CAGR, 18.2% volatility, -42% max drawdown (2008)
- **Momentum + quality**: 11.8% CAGR, 14.7% volatility, -32% max drawdown
- **Risk-adjusted**: 9.6% CAGR, 11.2% volatility, -24% max drawdown
- **Conclusion**: Quality overlay reduces drawdowns with minimal return sacrifice

4. **No look-ahead bias**: Only use data available at the time (no future peeking)
