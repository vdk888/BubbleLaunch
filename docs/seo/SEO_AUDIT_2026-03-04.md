### 3. ⚠️ No Geographic Targeting (GEO SEO)
**Issue**: Missing location information for French market targeting

**Current State**:
- ✅ Language targeting (FR/EN via hreflang)
- ❌ No geographic signals in HTML
- ❌ No LocalBusiness schema (if physical presence exists)
- ⚠️ Partial address in FinancialService schema (Paris, FR only)

**Impact**:
- Google doesn't know you're targeting France specifically
- Won't appear in "near me" or local searches
- Competitors with local SEO will outrank you

**Fix Options**:

**Option A: If you have a physical office/address**:
Add LocalBusiness schema to homepage:
```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Bubble Invest",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "YOUR_STREET_ADDRESS",
    "addressLocality": "Paris",
    "postalCode": "75001",
    "addressCountry": "FR"
  },
  "geo": {
    "@type": "GeoCoordinates",
    "latitude": "48.8566",
    "longitude": "2.3522"
  },
  "url": "https://bubbleinvest.org",
  "telephone": "+33-X-XX-XX-XX-XX",
  "priceRange": "€0-10/mois"
}
```

**Option B: If fully remote/no physical office**:
Add meta tags for geographic targeting:
```html
<meta name="geo.region" content="FR" />
<meta name="geo.placename" content="France" />
<meta name="geo.position" content="48.8566;2.3522" /> <!-- Paris coordinates -->
```

**Google Search Console**:
Set geographic targeting to France:
1. Go to Settings → Geographic Targeting
2. Select "Target users in: France"

**Time to Fix**: 30 minutes
**Priority**: 🟡 **MEDIUM** - Recommended for French market focus

### 5. ⚠️ Missing Performance Optimizations
**Issue**: No performance optimizations for Core Web Vitals

**Current State**:
- ❌ No lazy loading on images
- ❌ No preconnect for external fonts
- ❌ No resource hints (prefetch, preload)
- ❌ No WebP format for images
- ❌ No responsive images (srcset)
- ⚠️ JS files set to no-cache (good for dev, bad for prod)

**Impact**:
- Poor Core Web Vitals scores (affects Google rankings since 2021)
- Slower page loads (higher bounce rate)
- Worse mobile experience
- Lower search rankings

**Fixes Required**:

**A. Image Lazy Loading**:
Add to all images below the fold:
```html
<img src="..." alt="..." loading="lazy" />
```

**B. Font Preconnect** (ALREADY DONE ✅):
```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
```

**C. Critical CSS Preload**:
```html
<link rel="preload" href="/assets/styles/core-2026.css" as="style" />
<link rel="stylesheet" href="/assets/styles/core-2026.css" />
```

**D. WebP Images** (future enhancement):
Convert images to WebP format for better compression:
```html
<picture>
  <source srcset="image.webp" type="image/webp">
  <img src="image.png" alt="..." loading="lazy">
</picture>
```

**E. Cache Control** (production only):
Update `src/backend/config/express.js` for production:
```javascript
if (process.env.NODE_ENV === 'production') {
  res.setHeader('Cache-Control', 'public, max-age=31536000, immutable');
}
```

**Time to Fix**:
- Lazy loading: 30 minutes
- Preload: 15 minutes
- WebP conversion: 2 hours (if doing all images)
- Cache control: 15 minutes

**Priority**: 🟡 **MEDIUM** - Impacts rankings and UX
