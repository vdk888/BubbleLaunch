## THURSDAY - FRIDAY - Image Alt Text Audit ⏱️ 2-4 HOURS

### Why Alt Text?
- Improves accessibility (legal requirement)
- Helps image SEO
- Better user experience for screen readers
- Usually missing in modern SPAs

### Action Items:

**Thursday (2 hours)** - Audit:
```
[ ] Audit all 28 pages for missing alt text
[ ] Document findings (which pages/images need fixes)
[ ] Categorize by priority (hero > featured > icons)
```

**Friday (2 hours)** - Implementation:
```
[ ] Add alt text to hero images
[ ] Add alt text to featured images
[ ] Add alt text to all functional images
[ ] Test with screen reader (optional)
```

### Alt Text Guidelines:

**Good Examples**:
```html
<img src="portfolio-simulator.png" alt="Interactive portfolio simulator comparing risk parity and momentum strategies with historical backtesting data">

<img src="bubble-logo.svg" alt="Bubble investment AI agent logo">

<img src="metrics-chart.png" alt="Sharpe ratio and maximum drawdown performance metrics across 20 years of historical data">
```

**Bad Examples**:
```html
<img src="image.png" alt="">
<img src="image.png" alt="image">
<img src="image.png"> <!-- missing alt entirely -->
```
