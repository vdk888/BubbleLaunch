## ⚠️ Important Clarification: What is Bubble's Proprietary Technology?

**Bubble's Core IP (What We Built):**
1. **Multi-factor scoring engine**: Proprietary algorithms for momentum, quality, risk-adjusted scoring
2. **11-step automated process**: End-to-end workflow from data aggregation to execution
3. **Risk management framework**: Institutional constraints (max 30 positions, 1-10% sizing, progressive rebalancing)
4. **Multi-broker routing intelligence**: Automatic broker selection, capacity management
5. **Backtesting infrastructure**: 17+ years validation system

**What Bubble is NOT:**
- ❌ **NOT a data provider**: We use third-party sources (Uncle Stock for screening data, Yahoo Finance for historical prices)
- ❌ **NOT a broker**: Users maintain their own IBKR/Alpaca/Saxo accounts
- ❌ **NOT a custody platform**: Users own and control assets directly

**Third-Party Data Sources We Use:**
- **Uncle Stock**: External stock screening data provider (like Yahoo Finance, but for screening)
- **Yahoo Finance**: Historical price data for backtesting
- **Future**: AI-augmented sources (Perplexity API, LLM research enhancement)

**Important for Articles**: Never position Bubble as building proprietary data sources. Focus on proprietary **processing, scoring, and automation** of data from multiple third-party providers.
