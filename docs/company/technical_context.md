## Investment Agent POC (Public Showcase)

Our investment agent is a proof of concept that we use on our own portfolios and share publicly. It demonstrates our AI agent building capabilities.

### What it does:
- Automated portfolio management using AI agents connected to brokers (Alpaca, Interactive Brokers, Saxo)
- Risk parity, momentum, and quantitative strategies applied to ETF-heavy portfolios
- End-to-end workflow: screening → backtesting → allocation → execution
- 17+ years of historical data for strategy validation

### Current Status:
- **Founders' portfolios**: Fully automated with live broker connections
- **Public users**: Shared as educational POC on our website (portfolio simulator with 9 strategies)
- **Purpose**: Proves our technical capabilities — not a product for sale

### Technology Stack:
- Node.js/Express backend, vanilla JavaScript frontend
- Yahoo Finance API for historical data
- OpenRouter API for LLM integration (free models)
- Chart.js for data visualization
- Notion as headless CMS
