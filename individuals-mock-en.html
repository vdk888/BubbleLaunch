Our Method

What we learned building — and how to apply it to your projects

5 non-negotiable principles

No black box. Clear rules, applied with discipline by the agent:

  • Systematic Backtesting — No position without 10-20 year validation
  • Strict Position Sizing — 1-10% max, never more than 30 positions
  • Risk Parity 2 Levels — Thematic balance + intra-pocket balance
  • Regime Detection — 5 composite signals (VIX, yield, credit...)
  • Human Validation — The agent proposes, we decide

# Framework — Extract

RISK_PARITY_2L(portfolio):
  # Level 1: Thematic allocation
  themes = [AI, Intl_EM, Value, REITs, 
            Crypto, Commodities, Uranium, 
            Gold, SmallCap, Healthcare]
  
  # Level 2: Intra-pocket allocation
  for theme in themes:
    tickers = get_tickers(theme)
    cov_matrix = calculate_erc(tickers)
    weights = 1 / diag(cov_matrix)
    normalize(weights)
  
  combine_levels(theme_weights, intra_weights)

REGIME_DETECTION():
  signals = [VIX(), YieldCurve(), 
             CreditSpreads(), Momentum(), 
             MarketBreadth()]
  
  composite = weighted_average(signals)
  
  if composite > 60: return BULL
  if composite < 40: return BEAR
  return CAUTION
