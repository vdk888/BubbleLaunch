Projets open-source

Les repos qu'on maintient

Quatre projets publiés en MIT. Chacun répond à un besoin concret rencontré en construisant notre système d'agents.

bubble-cabinet

Gestionnaire de secrets chiffré (SOPS) pour projets multi-agents. Stocke et distribue les credentials d'environnement sans exposer de valeurs en clair dans les configs ou les logs.

MIT Python SOPS Secrets
bubble-ops-loop

Framework de supervision pour orchestrer plusieurs agents Claude Code en parallèle. Gère les dépendances de tâches, les relances automatiques et les rapports de statut via Telegram.

MIT Python Agents Claude Code
bubble-vps-platform

Configuration et scripts de déploiement pour une infrastructure VPS hébergeant des agents autonomes. Inclut les configs systemd, la surveillance, le backup automatique et les scripts de mise à jour.

MIT Shell Infra DevOps
bubble-skills

Bibliothèque de skills réutilisables pour Claude Code : recherche web, envoi Telegram, accès Google Workspace, transcription audio et plus. Installables en une commande dans n'importe quel projet agent.

MIT Markdown Skills Claude Code
Notre philosophie

Pourquoi publier en open source

Transparence

On ne prétend pas maitriser ce qu'on cache. Publier le code, c'est accepter d'être lu, critiqué, amélioré. C'est aussi la meilleure preuve que l'architecture tient debout.

Partage de savoir-faire

L'outillage autour des agents IA est encore très jeune. Chaque pattern qu'on documente fait gagner du temps à ceux qui construisent les mêmes choses de leur côté.

Responsabilité

Publier sous MIT, c'est s'engager : le code doit être lisible, maintenable, documenté. Ca nous oblige à faire les choses correctement, pas juste à faire fonctionner le truc chez nous.

On construit en public parce que c'est plus intéressant à plusieurs.
