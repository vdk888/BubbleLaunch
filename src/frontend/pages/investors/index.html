Accès Anticipé

Vos questions, nos réponses

Comment fonctionne concrètement Bubble Portfolio ?

Bubble est un agent d'investissement conversationnel. Vous dialoguez avec lui pour :

1. Définir votre profil (objectifs, horizon, tolérance au risque)
2. Explorer des stratégies (momentum, risk parity, value...)
3. Backtester vos scénarios sur 17+ ans de données
4. Construire votre allocation personnalisée
5. Automatiser l'exécution via votre courtier (IBKR, Alpaca, Saxo)

Tout est transparent : vous voyez les calculs, les règles, les performances historiques.

Quelles stratégies puis-je utiliser ?

Toutes les stratégies sont disponibles dans tous les plans. Bubble propose 9 stratégies backtestées :

• Risk Parity : équilibrage du risque entre actifs
• Momentum : tendance 3-12 mois
• Value & Quality : fondamentaux + qualité
• Low Volatility : minimisation de la volatilité
• Equal Weight : pondération égale
• Custom Mix : combinez plusieurs stratégies selon vos préférences

Chaque stratégie est expliquée, avec performances historiques, drawdowns, et Sharpe ratio. Aucune limite par plan.

Sur quels actifs puis-je investir ?

Actuellement, Bubble se concentre sur les ETFs à faibles frais :

• Actions : SPY (US), EFA (Europe/Asie), EEM (émergents)
• Obligations : IEF (Treasuries US 7-10Y)
• Matières premières : GLD (or)
• Immobilier : VNQ (REITs US)
• Cash : fonds monétaires
• Cryptomonnaies : via Crypto.com et autres API de brokers crypto
• Actions individuelles : pour un ciblage spécifique

Structure : Une stratégie par poche + une stratégie globale de portefeuille.

Dois-je transférer mon argent chez Bubble ?

Non, jamais. Bubble ne détient pas vos actifs.

Vous gardez vos comptes chez votre courtier habituel (Interactive Brokers, Alpaca, Saxo Bank). Bubble se connecte via API pour :

• Lire vos positions (en lecture seule)
• Vous suggérer des ordres (rebalancement, nouveaux trades)
• Vous validez chaque transaction avant exécution

Vous gardez 100% du contrôle de vos comptes.

Bubble est-il adapte aux debutants ?

Oui. Notre agent conversationnel est concu pour eduquer et guider :

- Explications en langage simple : pas de jargon technique
- Strategies predefinies ou personnalisees : choisissez parmi nos strategies eprouvees ou creez votre propre mix selon vos preferences
- Recommandations personnalisees basees sur vos reponses
- Backtests educatifs : comprenez comment chaque strategie reagit aux crises

Vous n'avez pas besoin d'etre un expert en finance quantitative.
