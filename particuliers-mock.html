Notre méthode

Ce qu'on a appris en construisant — et comment appliquer ça à vos projets

5 principes non-négociables

Pas de boîte noire. Des règles claires, appliquées avec discipline :

  • 1️⃣ Backtest systématique — Aucune décision sans validation historique
  • 2️⃣ Risk parity 2 niveaux — Thématique + intra-pocket
  • 3️⃣ Régime de marché — 5 signaux composites (VIX, yield curve, credit...)
  • 4️⃣ Position sizing strict — 1-10% max, jamais plus de 30 positions
  • 5️⃣ Validation humaine — L'agent propose, nous validons (et on vous explique pourquoi)

RISK_PARITY_2L(portfolio):
  # Level 1: Thematic allocation
  themes = [AI, Intl_EM, Value, REITs, 
            Crypto, Commodities, Uranium, 
            Or, SmallCap, Santé]
  
  # Level 2: Intra-pocket allocation
  for theme in themes:
    tickers = get_tickers(theme)
    cov_matrix = calculate_erc(tickers)
    weights = 1 / diag(cov_matrix)
    normalize(weights)
  
  combine_levels(theme_weights, intra_weights)

REGIME_DETECTION():
  signals = [VIX(), YieldCurve(), 
             CreditSpreads(), Momentum(), 
             MarketBreadth()]
  
  composite = weighted_average(signals)
  
  if composite > 60: return BULL
  if composite < 40: return BEAR
  return CAUTION
