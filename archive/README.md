# Archive Directory

This folder contains archived code that is no longer part of the active codebase but is preserved for reference.

## Directory Structure

### `/anim-main/`
Original React-based animation project that served as the foundation for the portfolio simulator. Contains the full 9-strategy implementation with React components.

### `/backend-backups/`
Archived backend files:
- `server.backup.js` - Monolithic server file (836 lines) before modular refactor
- `server.old.js` - Duplicate backup of monolithic server
- `riskBudgetingService.js` - Unused optimization helpers service

### `/data/`
Historical data files used during development.

### `/experiments/`
Experimental features and proof-of-concept code.

### `/frontend/`
Archived frontend files:
- `simulator-chat.js` - Original simulator chat implementation, replaced by `chat-side-panel.js`
- `/backups/` - Additional frontend backup files

### `/legacy/`
Legacy code from earlier project iterations.

### `/scripts/`
Archived utility scripts.
